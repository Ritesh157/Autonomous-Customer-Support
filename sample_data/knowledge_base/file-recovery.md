# Recovering deleted or missing files

## Self service

1. Check the trash, which keeps files for 30 days.
2. Check version history.
3. Review the folder activity log for moves.

## Data loss

If files are missing and not in the trash, stop further changes and escalate to the data recovery team. Do not promise recovery.
