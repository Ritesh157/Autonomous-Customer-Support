# Responding to a suspected account compromise

## Immediate steps

1. Sign out all sessions.
2. Reset passwords for affected accounts.
3. Revoke unknown API keys.
4. Enable multi-factor authentication.

## Escalation

Every suspected breach is escalated to the security team. Do not share log details of other customers.
